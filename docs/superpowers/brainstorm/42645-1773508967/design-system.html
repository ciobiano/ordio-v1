Two decisions to lock in

Orb implementation + accent color for monochrome UI

1. Orb Implementation

How we build the iridescent sphere

Shader (CSS/WebGL)

Animated, fluid. Colors shift in real-time. VAD directly drives the visual — intensity, speed, color warmth all respond to voice. More complex to build but maximum fidelity.

Pre-rendered (Lottie/Video)

Designed in After Effects, exported as Lottie. Beautiful but fixed animation. VAD controls playback speed and scale only — can't drive individual color channels. Simpler to ship.
